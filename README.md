# 麦分精算师 (mcd-points-advisor)

> 你的麦当劳积分管家：监控**即将过期积分**，在作废前推荐最优兑换组合，把每一分都花在刀刃上。
> 基于麦当劳官方 MCP 能力开发的参赛 Skill · 1024 程序员节「麦当劳程序员创意开发大赛」

---

## ✨ 它能做什么
- 📊 **积分体检**：一眼看清可用 / 累计 / 冻结 / **即将过期积分**及过期日
- 🛒 **商城扫描**：拉取麦麦商城可兑换商品，按积分价与类目整理
- 🎯 **过期预警 + 兑换建议**：把"即将过期积分"作为优先消耗池，贪心匹配高价值商品，**最大化过期积分利用率，避免白白作废**

## 🌟 为什么与众不同
| 维度 | 本项目 | 主流参赛项目 |
|---|---|---|
| 赛道 | 积分理财（蓝海，几乎无人做） | 省钱 / 点餐 / 派对（已 200+，极度内卷） |
| 安全性 | **纯只读** 3 个工具，零下单风险 | 不少涉及真实下单 |
| 可演示性 | 内置离线演示，无 Token 也能跑通 | 多数依赖真实账号 |

> 麦当劳 MCP 已开放 30+ 工具，但积分 / 商城类只读工具使用率极低——这正是蓝海。

## 🚀 快速开始

### 1. 申请麦当劳 MCP Token
打开 https://open.mcd.cn/mcp → 右上角【登录】→ 手机号验证 →【控制台】→【激活】→ 复制 Token。

### 2. 接入 WorkBuddy（官方推荐客户端）
左侧【专家·技能·连接器】→【连接器】→【自定义连接器】→【配置 MCP】，粘贴：
```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer 你的TOKEN" }
    }
  }
}
```
启用后即可在对话中说"我的麦当劳积分快过期了，帮我看看换什么最划算"。

### 3. 命令行直接运行
```bash
# 离线演示（无需 Token，立刻看效果）
python scripts/mcd_points_advisor.py --offline

# 实时模式（需设置环境变量）
export MCD_MCP_TOKEN="你的TOKEN"
python scripts/mcd_points_advisor.py            # 仅账户 + 商品列表
python scripts/mcd_points_advisor.py --detail   # 额外拉取商品详情
```
> ⚠️ Token 通过环境变量注入，绝不写入任何文件（见 `.gitignore`）。
